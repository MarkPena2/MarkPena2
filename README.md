### 👋 About Me

I'm a Software QA Analyst at **ManhattanLife**, working on a small QA team that builds and maintains **Playwright test automation** integrated with **Azure DevOps**. I care about turning manual, repetitive QA work into automated, closed-loop systems that actually get trusted by engineering teams.

- 🔭 Currently building out a phased QA automation system that extends Azure DevOps reporting into full closed-loop validation
- 🧪 Also working on internal tools like a Playwright-based CSS issue scanner and a mock API testing project (Swagger/Node.js/Express)
- 🎓 Background from Texas Tech University
- 📍 Based in Houston, TX
